# Fast Electron Vue Vite

快速启动 Electron Vue Vite 的开发

# 技术栈

- 核心框架
  - [Electron Forge](https://www.electronforge.io/): 快速搭建一个具备完整构建流水线的 Electron 项目
  - [Vue 3](https://cn.vuejs.org/guide/introduction.html)：用于构建用户界面的渐进式 JavaScript 框架。
  - [Vite](https://github.com/vitejs/vite)：一种新型前端构建工具, 能够显著提升前端开发体验。
- 工具库
  - [Vue Router](https://github.com/vuejs/router): Vue 官方的客户端路由解决方案。
  - [Pinia](https://github.com/vuejs/pinia): 符合直觉的
    Vue.js 状态管理库, 类型安全、可扩展性以及模块化设计。
- 组件样式
  - [Tailwind CSS](https://github.com/tailwindlabs/tailwindcss): 一个实用优先的 CSS 框架，用于快速构建自定义用户界面。
  - [daisyUI](https://github.com/saadeghi/daisyui): 最受欢迎的免费开源 Tailwind CSS 组件库。
  - [Phosphor Icons](https://github.com/phosphor-icons/homepage): 一套灵活的图标集合, 适用于界面、图表、演示文稿——实际上可用于任何场景。

# 快速启动

```bash
pnpm i
pnpm start
```
